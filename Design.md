# design.md: The Dream Machine

> Visual and interaction design. Read `rules.md` and `prd.md` first. This file covers the **app and website UI**. The look of the 3D dream world is defined separately in `config/styles/*.yaml`; section 11 derives those presets from this palette so the two always match.

## 1. Design intent

**Three words: Luminous · Hushed · Mythic.**

> Waking up inside a painting that remembers you.

The product is a glowing doorway. It is **night** when you capture (dim, quiet, kind to sleepy eyes) and **dawn** when you reflect (mist, green light, a thread of gold). Fantasy here means *wonder and scale*, not swords and parchment.

**Anti-goals (do not build these):**
- A generic dark-blue "AI dashboard" (navy panels, neon gradients, purple glow).
- Fantasy clichés: blackletter fonts, parchment textures, dragons, gothic ornament.
- Heavy glassmorphism, neon cyberpunk, rainbow gradients.
- Motion that shouts. Everything breathes; nothing snaps.

### 3.5 Theme selection (default: follows the time of day)

**Auto (default):** Night from 19:00 to 05:59 local time, Dawn from 06:00 to 18:59. The user can cycle **Auto, Night, Dawn**; the choice is remembered. The **Capture screen is always Night** (sleepy eyes). Theme changes crossfade colors over 1.2 s; on the landing page they use the watercolour wipe (17.6). Re-check every 15 minutes while on Auto.

An inline script in `<head>` sets the theme before first paint to avoid a flash:

```js
(() => { try {
  const pref = localStorage.getItem('theme');            // 'auto' | 'night' | 'dawn'
  const h = new Date().getHours();
  const auto = (h >= 19 || h < 6) ? 'night' : 'dawn';
  document.documentElement.dataset.theme = (!pref || pref === 'auto') ? auto : pref;
} catch (e) { document.documentElement.dataset.theme = 'night'; } })();
```

## 5. Shape, depth and texture

- **Arch is the signature shape:** cards, avatars, thumbnails and the portal use `border-radius: 999px 999px 24px 24px`. Other radii: 8 / 16 / 24.
- **Hairline frames:** 1 px `--hairline`. Major panels get a **double frame** (outer 1 px, inner 1 px inset 6 px) echoing the portal frame in reference 4L.
- **Depth by glow, not shadow:** `box-shadow: 0 0 0 1px var(--hairline), 0 12px 48px -12px rgba(226,184,102,.18)`.
- **Glass only on overlays:** 8 px backdrop blur, never on main surfaces.
- **Grain:** a fixed SVG noise overlay at 3-4% opacity with a soft vignette, `pointer-events: none`.
- **Spacing:** 4 px base scale (4, 8, 12, 16, 24, 32, 48, 64, 96, 128). Layouts are airy. Max content width 1200 px; reading column 62ch.

## 6. Motion and interaction

### 6.1 Principles
- Slow and breathing: reveals 600-900 ms, micro-interactions 150-250 ms.
- Easing: reveals `cubic-bezier(0.22, 1, 0.36, 1)`, state changes `cubic-bezier(0.45, 0, 0.2, 1)`, pointer following uses a spring (stiffness 120, damping 20).
- One focal motion per viewport.
- Every effect has a reduced-motion version and respects **Calm mode** (6.6).

### 6.2 Scroll ripple (signature effect)

The page behaves like a still pool that scrolling disturbs. Three layers:

**(a) Ripple reveal (section entry).** When a section enters, 3 concentric gold rings expand from the center of its headline while the content is revealed by an expanding circle:
- SVG rings: radius 0 to max, 1 px `--lantern` at 50% opacity fading to 0, 1600 ms, staggered 120 ms.
- Content: `clip-path: circle(0% at X Y)` to `circle(150% at X Y)` over 900 ms, plus fade and 24 px rise.
- Trigger: Motion (`motion/react`) `whileInView` or IntersectionObserver, once per section.

**(b) Water distortion (scroll velocity).** Large artwork (hero, section images) wobbles like water while you scroll and settles when you stop:
- Start with an SVG filter: `feTurbulence` (baseFrequency 0.008 to 0.015) plus `feDisplacementMap`, with `scale = min(14, |scrollVelocity| / 250)`.
- Smooth with a spring (stiffness 60, damping 18); it decays to 0 in about 600 ms.
- Upgrade path: a WebGL displacement shader (OGL or Three.js) with a radial wave `sin(dist * freq - time * speed) * amp * falloff` centered on the cursor or viewport. Only if the SVG version is not smooth enough.

**(c) Scroll-linked portal.** The supplied scroll-expansion hero (6.4).

| Parameter | Value |
|---|---|
| Rings per ripple | 3 |
| Ring stagger / duration | 120 ms / 1600 ms |
| Reveal duration | 900 ms |
| Max displacement | 14 px |
| Elements with distortion in view | max 2 |

Mobile: reveal rings only, no distortion. Optional smooth scroll with Lenis (MIT), but test it against the hero's wheel handling before combining.

### 6.3 Magic cursor trail ("stardust")

A lantern-gold spark leads the pointer, leaving a trail of drifting embers and stars, with a soft halo that lags behind. **Press and drag on the page to write with light** that drifts and fades (section 18, Dream Ink).

| Parameter | Value |
|---|---|
| Particles (max) | 40 |
| Emission | 1 per ~12 ms while moving |
| Size / life | 2-5 px / 700 ms |
| Drift | upward 12-30 px/s, slight outward spread |
| Color over life | `--lantern-soft` to `--lantern` to `--lake` to transparent |
| Shapes | mix of soft dots and tiny four-point stars |
| Blend | additive (`lighter`) in Night, normal at reduced opacity in Dawn |
| Halo | 28 px ring following with a spring; grows to 48 px over interactive elements with a 12% magnetic pull |
| Click | ripple ring 0 to 64 px over 600 ms plus a burst of ~10 sparkles (same language as the scroll ripple) |
| Idle (> 3 s) | trail fades, halo "breathes" slowly |

**Context rules:**
- Over text inputs, textareas and editable text: show the native text cursor, trail off.
- Over the 3D dream player: trail off or only the halo (do not disturb the film, and save GPU).
- Over dream cards: particle tint comes from that dream's palette.
- Touch or coarse pointers: disabled (tap ripple only).

**Technical rules:** one fixed full-screen 2D canvas overlay (`pointer-events: none`, `aria-hidden`), device pixel ratio capped at 2, `requestAnimationFrame` paused when the tab is hidden or the pointer is still, pooled particles (no allocation per frame), cost under 1 ms per frame. Hide the native cursor only on fine-pointer devices and never over form fields. The trail must never cover a focus indicator or be required for any function. In Calm mode or with reduced motion: a plain small dot, no trail.

### 6.4 Portal expansion hero (supplied component)

The landing hero uses the supplied **scroll-expansion-hero**: a small framed "window" expands to fill the screen as you scroll, like stepping through the portal in reference 4L. Headline words slide apart as it grows. The media becomes an exported dream film later; until then it is generated art. Integration and required fixes are in section 12. Art prompts A1 (portal window) and A2 (night void) are in section 21; the painted-scenery reveal that follows the hero is in section 17.

### 6.5 Other micro-interactions
- **Halo loader:** a rotating gold ring with a small star orbiting it; stage text beneath ("gathering the fragments", "painting the backdrops", "giving voices to shadows").
- **Dream pool (capture):** the text area reads as dark water. Typing or recording sends small ripple rings from the caret or mic. The mic button is a halo that pulses with input level.
- **Lantern buttons:** hover brings a soft glow and a tiny floating ember; press sends a ripple.
- **Page transitions:** an iris/ripple wipe from the click point.
- **Inferred-text glow:** AI-inferred passages carry a faint, slow gold shimmer underline (hover shows the reason).
- **Thread feedback:** "That resonates" lights a lantern (glow bloom); "felt different" dims it gently.
- **Dream cards:** subtle parallax tilt up to 4 degrees.
- **Sound:** soft chimes, water drops and a brush wash; off by default (section 19).

### 6.6 Calm mode, reduced motion and performance
- A visible **Calm mode** toggle disables the cursor trail, ripple distortion, particles and animated grain. It follows `prefers-reduced-motion` by default.
- **When the 3D player is running,** automatically disable the cursor trail, distortion and animated grain so the browser GPU is free for the film.
- Keep 60 fps on the UI. Lazy-initialize heavy effects after first paint.

## 12. Integrating the scroll-expansion hero

The supplied prompt targets a **shadcn + Tailwind + TypeScript** project.

**Setup (if the project lacks it):** in `apps/web`, run the shadcn CLI init (`npx shadcn@latest init`; check the current command in the shadcn docs), which also sets up Tailwind and the `@/` alias. Dependencies: `npm install motion` (Next.js is already present). The component imports `motion` from `framer-motion`; change that to `motion/react` (required change 8).

**Motion agent skill:** run `npx motion-ai` once. It installs the free `/motion` skill and sets up Motion's MCP servers so the agent writes current, performant Motion code. Stay on the free tier: do not sign in to Motion+ or add the paid `@motion` / `@motionplus` registries (keeps the project at zero cost). The README lists Claude Code, Cursor, Amp, OpenCode, Gemini CLI and Copilot (or a custom agent folder); Antigravity is not named, so you may need to point it at Antigravity's skills/MCP location manually.

**Placement and why `/components/ui` matters:** put the component at `apps/web/components/ui/scroll-expansion-hero.tsx`. shadcn's `components.json` aliases and CLI generate primitives in `@/components/ui`, and the demo imports `@/components/ui/scroll-expansion-hero`. Keeping that path means future shadcn components land beside it and imports keep working. Keep `demo.tsx` only as reference; do not ship its video/image switch buttons.

**Answers to the integration questions:**

| Question | Answer |

| Props | `mediaType`: `"image"` for MVP, `"video"` once a dream film exists; `mediaSrc`: `/art/portal-window.webp`; `bgImageSrc`: `/art/night-void.webp`; `title`: "Step Through the Dream"; `date`: "The Dream Machine"; `scrollToExpand`: "Scroll to step through"; `textBlend`: off (test it; the difference blend can look harsh on gold) |

**Required changes before shipping (the component as supplied has these issues):**
1. **Reduced motion:** if `prefers-reduced-motion` or Calm mode, render the fully expanded state at once and skip the scroll hijack.
2. **Keyboard access:** ArrowDown, PageDown and Space advance progress; Home or Escape resets. Add a visible **"Skip intro"** button.
3. **Tokens:** replace `text-blue-200` and the `bg-black/...` overlays with our palette (cloud, mist, void).
4. **Scroll lock:** it calls `preventDefault` on wheel and touch (non-passive) and `window.scrollTo(0,0)`, which blocks normal scrolling until expanded. Confirm listeners are removed after expansion and on unmount, test iOS rubber-banding, and do not combine with Lenis without testing.
5. **Video:** muted, `playsInline`, a poster image, and `preload="metadata"` on mobile to save data. No autoplay audio.
6. **Images:** use `sizes` on `next/image`, and `priority` only for the hero.
7. **Cleanup:** remove the unused `sectionRef`, and verify types for the DOM wheel/touch events (the casts are fragile).
8. **Import path:** change `import { motion } from "framer-motion"` to `import { motion } from "motion/react"` in the component and in `demo.tsx`.

## 13. Accessibility, performance, responsive

- WCAG AA minimum (ratios in 3.3). Gold fill buttons use `--void` text.
- Focus ring: 2 px `--focus` with 2 px offset, always visible, never covered by the cursor effects.
- Touch targets at least 44 px. Mobile-first capture with the halo mic reachable by thumb.
- Captions on all playback; arch icons get labels for screen readers.
- Respect `prefers-reduced-motion` and `prefers-reduced-data`; Calm mode as in 6.6.
- Sound is off by default and never autoplays. Dream Ink strokes are ephemeral: never stored, logged or sent anywhere.
- Breakpoints: 640 / 768 / 1024 / 1280.
- Budgets: cursor canvas under 1 ms per frame; at most 2 elements with distortion; effects disabled while the 3D player runs.

## 17. Watercolour scenery reveal ("paint the world")

### 17.1 Concept
The scenery starts as a quiet ink-wash sketch on paper. The visitor picks a part of it. The screen **focuses** there, and colour **bleeds outward slowly** like a wet wash until the whole painting, then the whole page, is in colour.

### 17.2 Where it appears
1. **Landing:** right after the portal hero expands, the painted scenery (A3) with 3-4 glowing hotspots.
2. **Recognition moment:** when the user approves a reconstruction, the sketch of the first scene bleeds into colour from the point they tap.
3. **Theme change** (Night to Dawn): a watercolour wipe from the toggle (17.6).

### 17.3 Flow
**idle** (sketch + hotspot halos) to **focus** (1.2 s dolly toward the hotspot, other areas dim and blur) to **bleed** (pigment spreads from the seed, about 6 s, ease-out) to **dry** (full colour, settling; rendering stops; the UI crossfades to Dawn). Several seeds can run together (max 4); clicking another area adds a second bleed.

### 17.4 Technique (analytic shader, cheap)
A full-screen quad in Three.js. The sketch state is derived in the shader from the colour image (luminance wash on paper tone). The reveal mask is a noise-perturbed distance field growing from each seed, with a darker rim where pigment pools. This is a starting sketch to adapt, not production code:

```glsl
uniform sampler2D uColor, uPaper;
uniform vec3  uSeeds[4];          // xy = uv, z = start time
uniform float uTime, uDuration, uSeedCount;
uniform vec2  uRes;
// fbm(vec2) noise helper omitted
void main() {
  vec2 uv = vUv;  vec2 asp = vec2(uRes.x / uRes.y, 1.0);
  vec3 col = texture2D(uColor, uv).rgb;
  float luma = dot(col, vec3(.299, .587, .114));
  vec3 paper = texture2D(uPaper, uv * 2.0).rgb;
  vec3 sketch = mix(paper, vec3(luma) * .55 + .35, .55);        // ink-wash state
  float reveal = 0.0, edge = 0.0;
  for (int i = 0; i < 4; i++) {
    if (i >= int(uSeedCount)) break;
    float t = clamp((uTime - uSeeds[i].z) / uDuration, 0.0, 1.0);
    t = 1.0 - pow(1.0 - t, 3.0);                                // ease-out
    float d = distance(uv * asp, uSeeds[i].xy * asp);
    float n = fbm(uv * 3.5 + t * .4) - .5;
    float r = t * 1.6;                                          // sweeps past the screen edge
    float m = 1.0 - smoothstep(r - .12, r + .02, d + n * .22);  // wet front, ragged edge
    reveal = max(reveal, m);
    edge = max(edge, 4.0 * m * (1.0 - m));                      // pooled-pigment rim
  }
  vec3 painted = col * (1.0 - .35 * edge);                      // darker rim
  painted *= .92 + .16 * texture2D(uPaper, uv * 3.0).r;         // paper granulation
  gl_FragColor = vec4(mix(sketch, painted, reveal), 1.0);
}
```

### 17.5 Parameters

| Parameter | Value |
|---|---|
| Focus dolly | 1.0 to 1.08x over 1.2 s; non-focused areas dim 30% and blur up to 6 px |
| Bleed duration per seed | 6 s, ease-out cubic |
| Noise | fbm, 4 octaves, scale 3.5, edge ragged amount 0.22 |
| Pigment rim darkening | 0.35 |
| Paper granulation | +/- 8% |
| Max simultaneous seeds | 4 |
| DPR / render mode | cap 1.5; render only while animating; zero GPU when dry |

### 17.6 Theme-change wipe
Use the View Transitions API (`document.startViewTransition`) with a `clip-path`/`mask-image` driven by an animated noise mask growing from the toggle's position, so Dawn paints over Night. Fallback: a 1.2 s crossfade.

### 17.7 Accessibility and performance
Hotspots are keyboard-focusable buttons (Enter starts the bleed). Reduced motion and Calm mode jump straight to full colour. Not used while the 3D player runs. Optional brush-wash sound (section 19).

### 17.8 Assets
Painting prompt A3 and hotspot data (section 21). Paper and noise are generated in code, not downloaded.

### 17.9 References (inspiration only; check each licence before reusing any code)
- Codrops, "Susurrus": a watercolour look with a Kuwahara shader and an intro reveal driven by a progress uniform on a screen quad.
- Immersive Garden's David Whyte experience: a watercolour reveal built from layered, pre-baked noise.
- `msurguy/watercolor-playground`: a real watercolour wash simulation (tap an area and a wash spreads and dries). Heavier than we need; useful for ideas.

## 18. Dream Ink (write on the page)

**Concept:** write anything on the page with light; the words drift like smoke and fade like a dream you can't quite keep. It is the product's idea in one gesture.

**Interaction**
- Hover leaves the stardust trail (6.3). **Press and drag on an empty, non-text area to write.** Text selection, links and form fields keep working normally.
- A **quill toggle** in the header turns on writing mode (needed on touch, where dragging would scroll). `Esc` exits.
- Landing hint: "Write something you remember. Watch it drift." After about 8 s of writing: "Don't let it fade. Step through."

**Stroke behaviour**

| Parameter | Value |
|---|---|
| Width | 1.5 to 6 px, thinner when fast, thicker when slow |
| Look | `--lantern-soft` core, additive `--lantern` glow at 35% |
| Drift | curl-noise flow, upward bias, 8-20 px/s |
| Life | about 5 s (6 s for long strokes); alpha ease-out; blur 0 to 3 px |
| End | the last second dissolves into dust particles |
| Caps | 12 strokes, 600 points, 120 dust particles |
| Smoothing | quadratic midpoint curves |

**Rules**
- Shares the MagicCursor canvas; under 1.5 ms per frame.
- Off over form fields, the 3D player and while the player runs.
- **Privacy:** strokes are ephemeral. They are never stored, logged or sent anywhere.
- Calm mode and reduced motion: strokes fade in 1.5 s, no drift, no dust.
- Never required for any function.

## 19. Sound (off by default)

All cues are synthesized with the Web Audio API, so there are no audio files and no licensing.

| Cue | Trigger | Recipe | Level |
|---|---|---|---|
| Water drop | Ripple reveal, click ripple | Sine 880 to 440 Hz over 120 ms, exponential decay, light reverb | -24 dB |
| Chime | "That resonates", dream approved | Two sines at 660 and 990 Hz, slight detune, 1.8 s decay | -22 dB |
| Brush wash | Watercolour reveal | Band-passed noise swelling over 1.5-6 s | -28 dB |
| Ink whisper | Dream Ink writing | High-passed noise, gain follows pointer speed | max -34 dB |
| Door | Logo hover, final CTA | Soft latch click plus a low air swell | -26 dB |
| Ambient bed | Landing only | Two detuned triangle oscillators through a slow low-pass plus faint wind noise, 4 s fade-in | -30 dB |

Rules: off by default; a speaker toggle in the header persists the choice; nothing plays before the user enables it; the AudioContext resumes on the first user gesture after enabling; master volume 35%; mute when the tab is hidden; sounds never carry information that is not also visible.
